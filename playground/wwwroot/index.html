Commands do not run in the browser. Each step replays the output that its command printed when the sample was recorded with scenetake. A step whose run text has no recording shows a line that says so. Demos operated from the keyboard, such as Copilot CLI and vim, are on the Cast → SVG tab.

An image is named by its file name, background.webp; a path such as ../background.webp finds the same image. Record your own

scenetake runs the commands of a YAML scenario for real and writes an asciinema v3 cast, an animated SVG, or an mp4. Install it, then write a scenario with scenetake init or download the one you edited here with .yaml.

npm install -g scenetake      # or: dotnet tool install -g scenetake
scenetake init                  # writes scenario.yaml
scenetake --format svg scenario.yaml

Scoop on Windows and single-file binaries for Linux, macOS, and Windows are in the Quick Start.

Pick the output for where you share it

WhereWhat it takesCommand
GitHub README Animated SVG scenetake --format svg scenario.yaml, then ![](scenario.svg)
X, Reddit Video (mp4) or GIF; not SVG scenetake --format mp4 scenario.yaml (needs ffmpeg). For X: scenetake mp4 scenario.cast --max-size 1280x1024
Zenn Uploads of PNG, JPEG, GIF, or WebP up to 3 MB; not SVG A GIF made from the cast with agg in Docker: docker run --rm -v "${PWD}:/data" ghcr.io/asciinema/agg /data/scenario.cast /data/scenario.gif --font-size 20 --last-frame-duration 0
On Windows, use the Quick Start command, which copies the GIF out of the container.
